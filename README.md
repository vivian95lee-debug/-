# 手機倉庫管理系統（示範版）

這是一個可直接在手機瀏覽器使用的倉庫管理系統雛形，適合學校管理以下庫存：

- 食材
- 文具
- 教具
- 玩具
- 電子設備
- 工作電腦 / 印表機

## 功能

- 📷 **手機拍照或上傳照片**（每筆紀錄可附一張圖片）
- 🎤 **語音輸入**（使用瀏覽器語音辨識 API）
- 🔢 **手動輸入數量**
- 📍 **紀錄存放地點**
- 🗂️ **分類管理**（可快速選擇倉庫類型）
- 🔍 **搜尋與篩選**
- 💾 **本機儲存**（使用 `localStorage`，重新開啟頁面仍保留資料）

> 注意：此版本為前端示範，資料儲存在使用者自己的裝置中。若需要多人協作、權限控管、跨裝置同步，可再擴充後端 API 與資料庫。

## 使用方式

1. 在專案根目錄啟動靜態伺服器：

```bash
python3 -m http.server 8000
```

2. 用手機開啟瀏覽器連到：

- 同網段電腦 IP：`http://<你的電腦IP>:8000`
- 或本機測試：`http://localhost:8000`

3. 新增庫存：
   - 選分類
   - 輸入品名
   - 輸入數量
   - 輸入存放地點（可用語音）
   - 拍照 / 上傳照片
   - 按「新增入庫」

## 技術

- HTML / CSS / JavaScript（無框架）
- Web Speech API（語音輸入）
- localStorage（本地資料保存）
